# Original references

`original/` contains the supplied reference pack, including its original README, gallery, manifest, style brief and plans. Its internal layout and image bytes are preserved so original links and captions continue to work.

Open [the reference gallery](original/index.html) or [the modelling brief](original/START_HERE_BLENDER_PROMPT.md). These are source inputs, not generated model previews. Current work is indexed in the [project README](../README.md).

Overlapping room views, walkway copies and full-screen captures are intentional evidence and are retained. Generated outputs belong in `docs/` and `renders/`; editable style assets belong in `assets/styles/`.
